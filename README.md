# EngSty

한국어의 의도를 자연스러운 영어 표현으로 배우는 반응형 프론트엔드 데모입니다.

## 실행

Node.js 24, Python 3가 필요합니다. 외부 npm 의존성은 없습니다.

```sh
npm run dev
npm test
npm run build
```

개발 서버는 5173 포트를 사용합니다. `dist/`는 GitHub Pages에 배포할 정적 결과물입니다. 사이트는 상대 경로를 사용하므로 `/EngSty/` 하위 경로에서도 동작합니다.

## 기능

- 일상·직장·여행 상황과 친근한/정중한 말투
- 준비된 한국어 표현 12개의 자연스러운 영어, 뉘앙스 설명, 대체 표현
- 브라우저 음성 합성, 복사, localStorage 표현집, 표현집 기반 복습
- 모바일 대응 및 키보드 탐색

현재 번역은 예시 기반입니다. 자유 문장 번역 API, 로그인, 서버 저장은 연결되지 않았습니다. 지원하지 않는 문장에는 안내를 표시합니다. 상황 선택은 해당 상황의 예시를 불러옵니다. 음성은 브라우저 지원 여부에 따라 달라지며, 표현집은 현재 브라우저에만 저장됩니다.

## 배포

`main`에 푸시하면 `.github/workflows/pages.yml`이 테스트·빌드 후 GitHub Pages로 배포합니다. GitHub 저장소 Settings → Pages → Source에서 **GitHub Actions**를 선택해야 합니다. API 키를 프론트엔드 코드에 넣지 마세요. 실제 번역 연결은 별도 서버 API가 필요합니다.
